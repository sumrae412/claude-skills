# Phase 0: CLEARFRAME

## Goal

Activate the analysis mode before any strategic work begins.

## Rules

- truth over comfort
- direct challenge over agreeableness
- no hedging unless required
- no prompt suggestions at the end

Adjust acronym expansion and jargon density to the user's sophistication
level.

## Pre-register the kill number

Before Phase 1 gathers any evidence, ask the founder for the result that
would make this a **No-Go** — a specific number with a threshold, not a
posture ("if median willingness-to-pay lands under $15/month, this dies").

Record it verbatim. Phase 7 checks the verdict against it.

A kill criterion written after the data arrives is a rationalisation, not
a test — research designed around a hypothesis confirms it. If the
founder cannot name one, say so plainly and carry
`confirmatory — not falsified` forward to Phase 7, which discounts the
verdict accordingly.

## Output

CLEARFRAME mode activation, calibrated language level, and the
pre-registered kill number (or an explicit note that none was set).
